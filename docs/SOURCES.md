# Sources

_BibTeX keys live in `sources/bibliography.bib`. When the user supplies a PDF, extract its text to `sources/extracts/<key>.md` so agents can quote from it precisely and cite page numbers. Keep each extract's original page breaks as `[p. N]` markers._

## Tiers
- **A: primary texts.** The Quran, Nahj al-Balagha, al-Sahifa al-Sajjadiyya, Mafatih al-Jinan, and the major hadith collections.
- **B: key works of ʿIrfan, and established scholarship.**
- **C: niche or secondary works.** Cited explicitly; use sparingly.
- **L: the lecture series itself**, cited as `L{NN} ¶{n}`.

## Reading list requested from the user
Priorities:
- ★★★ essential: the lectures rely on it heavily, or Book 2 can't be written without it.
- ★★ strongly useful.
- ★ nice to have.

"Lecturer used" means the transcripts name or quote the work.
