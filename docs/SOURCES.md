# Sources

_BibTeX keys live in `sources/bibliography.bib`. Text extracts of the PDFs the user supplies go in `sources/extracts/<key>.md` (or `.txt`) so agents can quote from them precisely._

## Tiers
- **A: primary texts.** The Quran, Nahj al-Balagha, al-Sahifa al-Sajjadiyya, Mafatih al-Jinan, and the major hadith collections (al-Kafi, Bihar al-Anwar, etc.).
- **B: key works of Shia ʿIrfan.** Classical and modern authorities, and established English translations.
- **C: niche or secondary works.** Allowed, but cited explicitly. Use sparingly.
- **L: the lecture series itself**, cited as `L{NN} ¶{n}`.

## Quran
- **Arabic text:** the Tanzil Uthmani text, to be placed at `sources/quran/quran-uthmani.txt`. Status: ☐
- **English translation:** to be chosen. Candidates: ʿAli Quli Qaraʾi (a Shia translation, widely used) or Shakir. Status: ☐
