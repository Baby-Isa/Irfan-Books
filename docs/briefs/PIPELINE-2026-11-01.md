## Stage 1: ladder (Opus)
Write `docs/ladders/NN.md` in the format of `docs/ladders/12.md`, plus `docs/briefs/NN-case.md` from `_TEMPLATE.md`:
- **Chapter level:** title, the one-sentence chapter point (from the book chain, sharpened if needed), the section chain (each section's point, each depending only on earlier ones; MECE).
- **Section level:** each section's point as one short plain sentence.
- **Paragraph level (TONE 47):** numbered steps, one per paragraph, written as the reader's chain of questions: for each step, the question it answers in italics, then the claim, then its source. Mark where a verse or quote sits and what work it does (raises or answers). Explanations needed first are nested (2a, 2b). Close each section with "Therefore: …".

- Check every quote against its source now and write "(checked)" beside it, with the exact page or ¶. Note any `[VERIFY]` Arabic.
